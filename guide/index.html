学习路线总览 ​

本知识库服务于两类目标：面试冲刺（对齐目标岗位要求）与日常工作（补齐实战深度）。内容按 10 份深圳前端岗位 JD 的并集组织，出现频次越高越优先。

一、如何使用本知识库 ​

你的处境推荐路径
刚开始备战，想要全局视角能力地图（JD 整合总纲） → 备战路线
已有明确目标岗位按岗位差异化准备 → 对应模块深读
想快速刷题过面面试冲刺 高频题库
想补齐日常工作深度按下方「模块地图」逐块深读

二、模块地图 ​

1. 语言与基础（A 级必守） ​

HTML5 与语义化 · CSS 布局与样式工程 · 响应式与多端适配 · JavaScript 核心机制 · TypeScript 工程实践

对应 JD 要求 A2：扎实 HTML5/CSS3/JS(ES6+)/TS 基础 + 浏览器原理。

2. 框架（A 级必守） ​

React 18/19 深入 · Vue 3 深入 · 状态管理与路由 · 双栈对比与同构组件库

对应 JD 要求 A1：熟练 React 或 Vue，且多数岗位要求双栈。

3. 工程化（A 级必守） ​

构建工具：Vite / Webpack · pnpm workspace 与 Monorepo · Git 工作流 · 代码规范与静态检查 · CI/CD 与自动化发布 · 组件库建设与发布

对应 JD 要求 A4（工程化工具）+ A5（组件库/公共能力建设）。

4. 质量与性能（A/B 级） ​

单元测试（Vitest） · 端到端测试（Playwright） · 架构约束与依赖治理 · 加载性能优化 · 渲染性能优化 · 大屏与大数据可视化性能

对应 JD 要求 A3（性能优化）+ B2（测试能力）。

5. 网络与安全（B 级） ​

HTTP 与请求层设计 · 浏览器跨域机制 · 实时通信：WebSocket / SSE · 音视频与 WebRTC · IM 即时通讯前端 · 前端 Web 安全 · 依赖治理与供应链

对应 JD 要求 B4（WebSocket/实时数据）+ B5（HTTP 请求层）+ B8（安全）。

6. 可视化与跨端（B/C 级） ​

ECharts 图表开发 · AntV 生态（G2/G6/X6） · 地图与三维数字孪生 · Electron 桌面端 · React Native 跨端 · Hybrid 与 JSBridge

对应 JD 要求 B3（可视化）+ C1（Electron）+ C2（React Native）+ C4（GIS/三维）。

7. 后端与全栈（B/C 级） ​

Node.js 与全栈基础 · Nest.js 后端框架 · 数据库与 BFF

对应 JD 要求 B9（Node.js/服务端基础）+ D 级全栈条款。

8. AI 工程（C 级 · 最强差异化） ​

大模型基础概念 · 流式渲染与 AI 交互界面 · 多模型接入与前端 SDK · Agent 编排与 RAG 界面 · AI 辅助研发与质量门禁

对应 JD 要求 C5/C6：4 份 JD 将 AI 能力列为加分或硬性要求。

9. 面试冲刺（全模块汇总） ​

面试总览与答题方法 · JavaScript 高频题 · React / Vue 高频题 · 浏览器与网络高频题 · 工程化与场景题 · 按岗位差异化准备

三、学习节奏建议 ​

  1. 第一遍（全局）：通读 能力地图 与各模块首段，建立坐标系。
  2. 第二遍（补弱）：对照 缺口汇总，只攻 ❌ 与 ⚠️ 条目。
  3. 第三遍（表达）：用 面试冲刺 题库把知识打磨成"被问到时能讲 3 分钟"的口语化表达。
  4. 投递前：按 备战路线 的"按岗临时补"清单做针对性预习。
