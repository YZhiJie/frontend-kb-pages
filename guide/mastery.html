本页目录

精通方向扩展路线（进阶指南） ​

定位：本站前 10 个模块解决覆盖面（面试通过 + 日常工作够用，即 L1-L2）；本页回答「往精通走，往哪扩、按什么顺序、拿什么证明」。精通不是知识更杂，而是在少数方向上完成 L3/L4 的跃迁。

一、精通的四层阶梯 ​

层级标准检验方式
L1 会用能在项目中正确使用 API 与最佳实践完成业务需求不踩坑
L2 懂原理能讲清"为什么这样设计"，答得上面试深挖白板讲原理 10 分钟不卡壳
L3 能实现读过源码 / 造过简化轮子，知道边界在哪手写 mini 版本（mini-react/mini-vite）
L4 能输出架构决策、开源影响力、带人开源项目有真实用户 / 团队规范出自你手

现状定位：组件库工程化已在 L3（577 测试 + npm 发布 + CI 闭环），AI-First 方法论在 L3-L4（有流程有门禁有产出数据），其余模块大多在 L1-L2。本页的任务是选 1-2 条主线冲 L3/L4。

二、七条精通方向总览 ​

方向对应模块赛道价值简历契合度起点
1. 工程架构与基建组件库 · 架构约束稀缺：会造基建的前端少最高（已有 XUI 资产）L3
2. AI 前端专家Generative UI · 流式渲染 · Agent/RAG最大红利：AI Native 产品井喷高（AI-First 已逐字命中 #11）L2
3. 音视频专家WebRTC · 媒体专项高溢价：音视频前端长期稀缺中（有 ffmpeg/WebSocket 桥接）L1
4. 性能专家加载 · 渲染稳定刚需，与监控/大屏联动中高（大屏/适配实战）L2
5. 框架原理React · Vue · JS 核心面试硬通货，全岗位通用高（双栈 + 响应式原理已有）L2
6. 可视化/图形学ECharts · 地图三维偏门但大屏/数字孪生需求稳中（fabric.js + Three.js 接触）L1-L2
7. Node 全栈Node · Nest · BFF全栈溢价，BFF/工具链入口中（了解级）L1

三、逐方向展开：现状 → 补什么 → 里程碑 ​

方向 1：工程架构与基建（推荐主线，起点最高） ​

  • 现状：XUI 组件库已具备契约驱动架构、monorepo、changesets、CI 全自动——这是多数 5 年经验的前端都没有的完整闭环。
  • 精通补强：
    • 主题系统进阶：Design Token 三层体系（全局 → 组件 → 实例）、暗色主题的语义化变量设计；
    • 无障碍（a11y）与键盘导航：WAI-ARIA 模式库（combobox/dialog/menu 的完整键盘交互）；
    • SSR/RSC 兼容与 use client 边界设计；包体积治理（tree-shaking 验证、sideEffects、按需加载矩阵）；
    • 微前端与模块联邦：多团队共用基建时的版本隔离与样式隔离方案；
    • AST 与代码修改：Babel/ESLint 自定义规则（把架构约束写成工具，而非口头规范）。
  • 里程碑产出：XUI 升级 v1.0——补 a11y 审计报告 + SSR 兼容 + bundle 治理看板；写 1 篇《契约驱动双端组件库》长文。
  • 精通检验：能否手写一个 mini-vitest？能否讲清 changesets 为什么优于 lerna？能否用 ESLint 自定义规则实现"禁止跨层 import"？

方向 2：AI 前端专家（推荐主线，赛道红利最大） ​

  • 现状：流式渲染有实战（AI 客服），AI-First 方法论完整，GenUI/Agent/RAG 停在概念级（L2 不到）。
  • 精通补强：
    • GenUI 从概念到实现：自建组件注册表 + 流式 JSON 解析 + 骨架二段渲染 demo（本站 Generative UI 页的示例扩展成真实项目）；
    • Agent 前端编排：工具调用可视化（调用树/重试/并行）、多 Agent 状态机、human-in-the-loop 确认流；
    • 本地推理：WebGPU + WebLLM 跑通 1 个浏览器内小模型，理解量化与显存约束；
    • 协议层：MCP（Model Context Protocol）前端接入、OpenAI Realtime API 语音链路；
    • RAG 界面工程化：引用溯源、相关性反馈、分块可视化调试界面。
  • 里程碑产出：开源一个「AI Chat 前端最佳实践」项目（流式 + GenUI + 工具调用可视化三合一），对标 vercel/ai 的 React 生态但补 Vue 侧空缺——Vue 生态的 AI UI 库几乎空白，是差异化机会。
  • 精通检验：能否讲清 SSE 流式中断恢复的完整方案？能否设计一个 Agent 工具调用的前端状态机？

方向 3：音视频专家（若投 #11/#8/#1 则临时升为主攻） ​

  • 现状：ffmpeg 操作实战 + WebSocket 推送，WebRTC/MSE 概念级（L1）。
  • 精通补强：WebRTC 完整链路实操（信令服务器手写 → 双人通话 demo → SFU 概念）；WebCodecs 帧级编解码；播放器自研（MSE + hls.js 源码阅读）；音频处理（Web Audio 图 + AudioWorklet）。
  • 里程碑产出：浏览器双人通话 demo（自写信令）+ 一个 MSE 直播播放器 demo。
  • 精通检验：能否讲清 ICE 穿透全过程？能否解释卡顿率与丢包率的统计口径？

方向 4：性能专家 ​

  • 精通补强：性能监控 SDK 完整实现（监控三件套扩展为真实上报 + 看板）；Chrome 性能面板深度（Performance/Performance/Memory 三面板熟练）；渲染管线级理解（合成层提升、paint flashing、GPU 栅格化）；Web Vitals 全指标优化手册（INP 是新重点）。
  • 里程碑产出：性能 SDK 开源（异常 + 性能 + 埋点 + sourcemap 还原），配一个真实站点的优化前后对比报告。
  • 精通检验：给定一个卡顿页面，能否 30 分钟内定位到主因？

方向 5：框架原理（面试刚需，投入产出比最高） ​

  • 精通补强：手写 mini-react（Fiber 遍历 + useState 闭包 + diff）；手写 mini-vue 响应式（Proxy 依赖收集 + 调度器）；Vue 编译器管线（template → AST → transform → generate）；React 并发调度（lane 模型、可中断渲染）。
  • 里程碑产出：两个 mini 仓库挂 GitHub，配博客长文——这是面试"深入理解 React 核心原理"（#11 原话）的最硬证明。
  • 精通检验：面试问"useState 闭包陷阱""为何 Vue 不需要 key 反查"时能否到源码层回答。

方向 6：可视化/图形学 ​

  • 精通补强：ECharts 源码级（zrender 渲染层、大数据量的 LTTB 降采样）；WebGL 基础（矩阵变换、着色器 GLSL 入门、手写三角形）；D3 数据 join 思想（图形语法理论）。
  • 里程碑产出：手写 WebGL 渲染 10 万点散点图（对比 ECharts large 模式），一篇《Canvas 性能天花板在哪》。

方向 7：Node 全栈 ​

  • 精通补强：libuv 与事件循环（与浏览器差异）；Stream 背压；Nest.js 依赖注入原理；数据库索引与慢查询；Dockerfile 多阶段构建前端应用。
  • 里程碑产出：XUI 文档站加一个真实 BFF（评论/统计接口）上线，走通 PM2/Docker 部署。

五、节奏与检验 ​

  1. 两周一个里程碑：每方向拆成可交付的小产出（demo/仓库/长文），避免"学了但没证据"；
  2. L3 的统一检验法：给该方向写一个 mini 实现——写不出即说明还停在 L2；
  3. L4 的统一检验法：该方向的产出是否有陌生人的 Star/Issue/使用——没有就继续做减法打磨；
  4. 与求职的关系：本站模块页保证"面得过"，本页的主线保证"谈得深"——面试终面与定级差异，就在 L3/L4 的证据上。

面试要点 ​

  1. "精通"怎么证明而不是口头？ 三件套：开源产出（mini 轮子/组件库）+ 源码级回答 + 量化战绩，本页每方向的"里程碑产出"就是为此设计。
  2. 为什么选工程架构 + AI 前端做主线？ 资产复用最大化（已有 XUI 与 AI-First 方法论）、赛道红利（AI Native 井喷）、市场稀缺（Vue 生态 AI UI 库空白）。
  3. 面到源码答不上怎么办？ 承认边界 + 给方法论："这个细节我没读到那一层，但按 xx 的架构推测应该是 yy，我会回去验证"——比硬编可信。
  4. 精通与广度矛盾吗？ 用"一专多能"回答：本站 10 模块是多能（L1-L2 保底），1-2 条主线是一专（L3/L4 定级），招聘要的正是这个组合。
